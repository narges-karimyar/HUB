# MyPatientHUB

A responsive healthcare dashboard where users can find doctors, clinics, and manage appointments.

## Technologies Used

- React
- JavaScript
- Tailwind CSS
- React Router
- React Icons

## Features

- Login page
- Dashboard
- Sidebar navigation
- Find Doctor page
- Find Clinic page
- Find Market Place
- Responsive design
- Easy page navigation with React Router
